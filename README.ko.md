# Copy It 0.4.5

Cities: Skylines II용 오브젝트 복사 모드. **업데이트 시험 빌드이며 실제 게임 내 검증은 아직 수행하지 않았습니다.**

## 설치

게임을 종료한 뒤 PowerShell 7에서 이 폴더의 `install.ps1`을 실행하세요. `local/CopyIt`의 DLL, UI 모듈, CSS, 아이콘을 게임의 `Mods/CopyIt`에 복사하고 SHA-256을 비교합니다. 기존 Copy It이 있으면 작업 폴더의 `installation-backups`에 먼저 백업합니다.

또는 `local/CopyIt` 폴더 전체를 아래에 복사하세요.

`%USERPROFILE%\AppData\LocalLow\Colossal Order\Cities Skylines II\Mods\CopyIt`

게임 공식 툴체인을 사용하는 **독립 모드**입니다. Move It 설치는 필요하지 않습니다. 공개 게시/Paradox Mods 업로드는 하지 않았습니다.

## 사용

1. 게임 플레이 중 **Ctrl+C**를 누르면 바로 Copy It 선택 모드가 열립니다. 우상단 아이콘도 사용할 수 있습니다. 텍스트 입력/오버레이에서는 단축키를 받지 않습니다.
2. 건물/프롭/나무 필터를 선택합니다. 클릭은 단일 선택, Shift+클릭은 추가·해제입니다.
3. 박스 선택은 드래그 중 기준점이 영역 안인 오브젝트를 테두리로 강조합니다. 다각형 선택은 클릭으로 최대 32개 꼭짓점을 찍고 첫 점 클릭/Enter/선택 완료로 확정합니다. 우클릭은 마지막 점, Esc는 그리는 영역을 취소합니다. Shift로 시작하면 기존 선택에 추가하며 최대 256개입니다.
4. Ctrl+C 또는 **복사** 버튼을 누르면 현재 프리팹·위치·회전을 스냅샷으로 저장하고 배치 미리보기를 시작합니다. 단축키는 게임 옵션의 Copy It에서 바꿀 수 있습니다.
5. 위치를 가리키고 클릭합니다. 클릭 시 위치를 잠근 뒤 미리보기와 게임 배치 조건을 확인해 적용합니다. 클릭을 반복해 같은 그룹을 여러 번 배치할 수 있습니다.
6. 복사 중 **우클릭 좌우 드래그**로 그룹 중심이 마우스의 지형 위치를 따라가면서 회전합니다. **Shift+휠 한 눈금은 1°**입니다. 드래그 중과 해제 후 모두 마우스 위치를 그대로 따라갑니다. **Esc**로 복사를 취소합니다. 선택 영역을 그리지 않는 선택 모드에서 우클릭하면 선택만 해제하고 패널은 유지합니다.

## 높이

그룹의 X/Z 경계 중심을 커서 기준점으로 사용하고, 선택된 원점 중 가장 낮은 Y를 높이 기준으로 사용합니다. 지형 높이는 커서 아래의 지표면 한 지점에서 읽습니다. 오브젝트마다 따로 지형 높이를 더하지 않으므로 경사지에서도 그룹 내부 높이 차이는 유지됩니다.

| 모드 | 계산 | 원본 Y 1.5 / 1.7m, 목표 지형 3m |
|---|---|---|
| 지형 기준 | 새 Y = 목표 지형 + 원본 Y − 그룹 최저 Y | 3.0 / 3.2m |
| 절대값 기준 | 새 Y = 원본 Y | 1.5 / 1.7m |

높이는 메시의 밑면이 아닌 **오브젝트 Transform 원점**을 기준으로 합니다. 복사 후에는 게임의 기본 Elevation 성분으로 위치를 유지합니다. 자동 개별 지형 재정렬이 그룹을 뒤틀지 않도록 루트의 OnGround 경로를 사용하지 않습니다. 따라서 나중에 지형을 바꾸면 지형을 자동 추종하지 않을 수 있습니다. 절대 모드에서는 지형 아래에 놓이거나 공중에 뜰 수 있습니다.

## 지원 범위와 제한

- 현재 대상은 **독립적인 정적 건물·프롭·나무·데칼, 도로 구간과 독립 NetLane**입니다. 같은 프리팹으로 새로운 오브젝트를 생성합니다. 원본을 옮기지 않습니다.
- 건물 기본 프리팹의 하위 오브젝트·내부 네트워크·영역은 게임의 `ObjectToolBaseSystem.CreateDefinitions`로 생성합니다. 원본에 나중에 추가/변경된 하위 장식, 시설 업그레이드, 다른 모드 전용 성분은 그대로 복제하지 않습니다.
- 루트의 위치·회전, 나무 성장 상태, 난수 시드, 사용 중인 CustomMeshColor 값을 보존합니다. 프리팹 내부 장식의 개별 색상·성장 상태·랜덤 배치까지 동일하다는 보장은 없습니다.
- 철도/전력선, 영역, 차량, 시민, 부착 시설은 복사 대상이 아닙니다. 도로 내부의 자동 생성 차선과 건물 소유 네트워크는 개별 복제하지 않습니다. NetLane/데칼용 컨테이너만 지원합니다. 자식 장식을 클릭하면 적격 부모를 선택합니다. 박스/다각형은 화면에 투영된 Transform 기준점(네트워크는 곡선 중점)의 영역 포함 여부로 선택합니다. 메시나 부지의 경계 상자가 걸치더라도 기준점이 밖이면 제외합니다. 기준점은 메시의 시각적 중심과 다를 수 있으며 가려진 대상도 포함될 수 있습니다.
- 게임의 배치 오류 검사와 비용 처리를 사용합니다. 도로 접근, 공간 충돌 등 조건에 따라 배치가 거부될 수 있습니다. 비용을 없애거나 충돌 검사를 해제하지 않습니다.
- 원본 주민·세입자·차량·경제 데이터는 복제하지 않습니다. 새 건물의 작동, 도로 연결, 성장/철거 조건은 게임 규칙에 따릅니다.
- 실행 취소는 이 버전에 없습니다. 그룹 Y축 회전을 지원하며 원본의 개별 기울기는 유지합니다. 선택/클립보드는 세이브에 저장하지 않으며 도시 로드 때 비웁니다.

## 0.3.0 도로·NetLane·데칼 — 실험 기능

필터에 도로, NetLane, 데칼을 추가했습니다. 세 선택 방식에서 섞어서 선택할 수 있습니다. 전체 256개 제한에 더해 네트워크 복사는 64구간으로 제한합니다. 영역 선택 시 곡선 중점이 들어온 구간 전체를 선택하며 경계에서 잘라 복사하지 않습니다.

- 도로: 독립 Game.Net.Edge/Curve + RoadData 구간. 원본 곡선 네 제어점, 구간 Upgraded 플래그, 선택 구간 사이의 공유 노드 관계를 스냅샷으로 보관합니다.
- NetLane: NetData를 가진 독립 Edge 컨테이너의 EditorContainer.m_Prefab이 NetLaneData인 경우. 도로 내부 시뮬레이션 차선, AreaLane 및 건물 소유 길은 제외합니다. 해당 도로/건물의 기본 하위 구조는 게임이 재생성합니다.
- 데칼: MeshFlags.Decal인 일반 오브젝트 또는 렌더 프리팹 컨테이너. 컨테이너의 크기와 강도를 보존하며 원본 기울기, 그룹 회전, 높이 정책을 적용합니다.

네트워크는 CreationDefinition + NetCourse를 게임 GenerateNodesSystem/GenerateEdgesSystem에 전달합니다. 원본 노드/구간/소유자 ID를 생성 정의에 넣지 않습니다. 같은 위치의 새 노드가 게임에서 결합된 후, 공유 노드가 갈라지거나 별도 노드가 합쳐지지 않았는지 확인합니다. 선택 밖 구간에 연결되거나 기존 네트워크의 임시 재생성/수정이 나타나면 배치를 거부합니다. 따라서 기존 도로에 자동 접속해 합치는 기능은 없습니다.

높이는 모든 네트워크 제어점을 포함한 그룹의 최저 Y 기준입니다. 새 노드와 구간에 Elevation이 남도록 생성하여 개별 지형 재스냅을 방지합니다. 프리팹, 네 제어점, 업그레이드 플래그, 새 노드 관계, 게임 오류 검사와 데칼 크기/강도가 모두 맞아야 적용합니다. 엔진이 곡선이나 노드를 예상과 다르게 재구성하면 보수적으로 배치를 거부합니다. 배치 후 검증 실패 시 반복 복사를 중단하며 자동 롤백은 하지 않습니다.

교차로 신호 운영, 다른 모드의 차선 규칙/표지판 설정, 도로 이름, 교통량, 건물 입주자 등 시뮬레이션 데이터는 복사하지 않습니다. 게임의 비용·배치·지형 변경 규칙을 사용합니다. 특히 도로/NetLane 생성, 주행 가능 여부, 저장/재로드는 아직 인게임에서 검증하지 못했습니다. TESTING.ko.md에 추가된 테스트용 도시 시나리오로 확인해야 합니다.

성공 효과음은 생성 확인 완료 후 한 번 재생합니다. 건물이 포함되면 내장 건설음, 도로만 포함되면 내장 도로 건설음, 나머지는 프롭 배치음을 사용합니다. 실패 시 성공음은 재생하지 않습니다. 실제 게임의 소리와 혼합 배치 성공 검증은 별도로 필요합니다.


## 0.3.5 도구 전환 예외 수정
ToolSystem은 MainLoop에서 이전 도구의 OnStopRunning을 호출하고 그 뒤 ToolUpdate에서 ToolOutputBarrier를 허용합니다. Copy It의 ClearState가 종료 시 DestroyDefinitions를 통해 금지된 시점에 ECB를 요청하여 발생한 예외를 수정했습니다. 종료 정리는 의존성 완료 후 생성 정의를 즉시 제거합니다. 불도저 등 다음 도구 단계로 전역 정의 정리를 지연하지 않습니다. 이미 배치된 오브젝트는 생성 정의 쿼리 대상이 아닙니다. 기본 도구 종료/입력 해제는 finally에서 실행합니다.
게임에서 배치 성공 후 B, 미리보기 중 B, 패널 닫기, Esc, 다른 도구 전환을 확인해야 합니다. 빌드·자동 검사와 실제 게임 검증은 구분합니다.


## 0.4.0 패널 이동 / 경로 / 에셋 스포이드
- 펼친 패널의 헤더 배경을 왼쪽 드래그하면 이동합니다. 접힌 패널은 맨 왼쪽 점 핸들을 드래그합니다. 드래그 중 scale 0.97 및 불투명 배경을 적용하고, 마우스를 놓으면 복원합니다. 이동 위치는 모드가 열려 있는 UI 세션에서 두 패널 간 공유합니다.
- 도로 외 경로는 TrackData/PathwayData의 독립 철도·트램·지하철·보행 경로입니다. 기존 도로와 독립 NetLane 필터는 별도 유지합니다. 건물 소유 하위 경로, 시뮬레이션 차선, 수도·전력 같은 유틸리티는 이 필터의 대상이 아닙니다. 지하 전용 선택 모드를 추가한 것은 아닙니다.
- 2개 이상 선택하면 스포이드 버튼이 활성화됩니다. 누른 뒤 기존 선택 안의 하나를 클릭하면 같은 PrefabRef와 EditorContainer 하위 프리팹을 가진 것만 남깁니다. 같은 유형이나 같은 표시명만 가진 다른 프리팹은 섞이지 않습니다. 우클릭/ESC는 스포이드만 취소합니다.
- 게임의 기본 생성/건설 조건 검사는 유지합니다. 추가 경로의 실제 배치 및 저장/불러오기 검증은 별도로 필요합니다.


## 0.4.1 선택 효과음과 유형 더블클릭
스포이드로 같은 에셋만 남기는 데 성공하면 내장 SelectEntity 효과음을 한 번 재생합니다. 취소나 선택 밖 클릭에는 재생하지 않습니다.
유형 버튼을 250ms 이내에 두 번 누르면 해당 유형만 켜집니다. 느린 클릭은 기존 토글이며, 다른 버튼을 누르거나 도구가 종료되면 연속 클릭 판정을 초기화합니다. 펼친/접힌 패널 모두 동일하게 적용합니다. 이미 선택된 오브젝트 목록을 자동 삭제하는 기능은 아닙니다.


## 0.4.2 먼저 에셋을 지정하는 스포이드
선택이 0개일 때도 별도 에셋 선택 도구의 스포이드 아이콘을 사용할 수 있습니다. 월드에서 지원되는 에셋 하나를 찍으면 선택 개수는 그대로 0이며, 이후 클릭/박스/다각형의 후보와 확정 선택 모두 동일 프리팹만 통과합니다. 이름이 같아도 서로 다른 프리팹은 섞이지 않으며 컨테이너 하위 에셋도 구분합니다. 샘플 유형은 자동으로 켜집니다.
필터 이름 옆 X로 에셋 필터를 해제합니다. 선택 해제는 필터를 유지하므로 다른 영역에서 반복 검색할 수 있습니다. 도구를 닫으면 필터가 초기화됩니다. 이미 선택한 오브젝트가 있을 때 스포이드는 기존처럼 그 목록 안에서 같은 에셋만 남깁니다. 스포이드 대기 중 ESC/우클릭은 샘플링만 취소합니다.


## 0.4.3 지형에 붙이기
새 높이 모드는 원본의 절대 높이와 상대 높낮이를 무시하고 각 오브젝트 기준점의 배치 XZ 위치에서 지형 높이를 샘플링합니다. 가로 배치와 회전 조작은 유지합니다. 기준점을 지형에 붙이는 기능이며 건물 메시 자체를 변형하거나 기울이지 않습니다.
도로·경로는 끝점과 구간 1/3, 2/3의 지형을 샘플링해 높이 곡선을 맞춥니다. 긴 구간의 세부 지형 굴곡과의 완전 밀착은 보장하지 않으며 프리팹의 직선 강제 등 게임 생성 규칙이 적용됩니다. 기존 지형 기준(그룹 상대 높이 유지), 절대값 기준도 그대로 선택할 수 있습니다.
게임 내 경사지 배치 검증은 별도로 필요합니다.


## 0.4.4 다각형 시작점 자석
꼭짓점을 3개 이상 찍은 뒤 첫 점의 8px 이내(1080p 기준, 화면 높이에 비례)에 접근하면 미리보기 끝점이 첫 점에 붙습니다. 붙은 상태에서 클릭하면 완료합니다. 경계에서 깜빡이지 않도록 12px 밖으로 나가면 해제합니다. 중복 시작점을 후보 다각형에 넣지 않으며 Enter 완료도 유지합니다. 실제 게임 조작 검증은 별도로 필요합니다.


## 0.4.5 UI 구분 개선
넷레인 표기를 한글로 변경했습니다. 지형에 붙이기는 내려오는 화살표/지면 위 블록 아이콘이며, 프롭은 벤치와 가로등을 나란히 표시합니다. 선택 도구 아래 구분선은 선택 방식 3개 아래로 이동했습니다.
접힌 패널에서 펼치기는 청색, 닫기는 적색입니다. 왼쪽 핸들 다음의 청색 선택 방식 아이콘은 현재 방식을 표시하며 누를 때마다 클릭 → 박스 → 다각형 → 클릭 순서로 전환합니다. 복사 중에는 선택 방식 변경을 비활성화합니다.
